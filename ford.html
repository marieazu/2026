Ford

Scaling a Design System Across Europe

Design Systems  •  Automotive

Context

Ford was rolling out a new global art direction, with the US site setting the visual benchmark. The European platform needed to align with this direction while supporting multiple internal teams contributing in parallel. Over time, the existing design system had become fragmented and difficult to maintain.

Core Challenge

Our objective was to create a single, scalable design system that supported multiple teams and aligned with the global visual direction. We had to ensure the system met strict accessibility standards without compromising the speed of delivery across diverse European markets.

Strategic Approach

The work focused on transforming a fragmented set of design assets into a dependable framework. We established a single source of truth for consistency and long-term scalability. This required auditing real-world usage in both design and code, working closely with engineering to restructure the system around tokens and variables rather than static styles.

1. Establishing a Single Source of Truth

Reducing redundancy through systematic auditing

With too many font sizes, components, and style variations in circulation, designers were frequently unsure which options were canonical, leading to inconsistent outputs across teams.

Solution: We audited all existing design files and cross-referenced them with the live production environment. Where multiple variations existed, we prioritised those already implemented in code and those that met accessibility standards most reliably. This allowed us to strip away redundancy and clearly define a core set of components.

2. Architecture for Scalability

Future-proofing the system through Figma variables

Given the scale of the Ford ecosystem, even minor updates risked being time-consuming and prone to human error if handled manually.

Solution: We rebuilt the system using Figma tokens and variables. This allowed for global changes to be made centrally and applied instantly across the entire library. We defined a clear naming convention in collaboration with engineering, ensuring that the design architecture aligned perfectly with technical implementation patterns.

3. Accessibility as a System Constraint

Encoding WCAG standards into the visual language

The system required a wide colour palette plus light and dark modes, creating a vast number of potential colour combinations. Ensuring every pair met WCAG AA standards was a significant manual burden.

Solution: We created a comprehensive colour reference that documented all approved combinations and explicitly excluded pairings that failed accessibility checks. By building these constraints directly into the system documentation, accessibility became a repeatable standard rather than an afterthought that designers had to re-evaluate for every new screen.

Impact

The result was a unified design system that acted as a reliable foundation for Ford Europe's digital products. It established a level of design governance that reduced inconsistency and lowered the risk of errors during rapid iteration.

Efficiency: Enabled teams to move faster with more confidence within a clear, scalable framework.

Consistency: Created a 1:1 parity between design assets and production code.

Inclusivity: Built accessibility into the core DNA of the system, ensuring compliance across all European touchpoints.
